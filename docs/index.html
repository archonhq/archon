The control room for your AI agent fleet.
See what they're doing. Stop them when they're not.

Archon is a local-first control plane for people running multiple AI agents and automations. Most tools only watch your agents — Archon also controls them.

Star on GitHub Self-host it

Why Archon

👁See

Every agent session, automation, and service on one pane — live, via SSE, not 10-second polling.

⚡Control

Kill switches, start/stop automations, restart services. The part nobody else ships.

🔔Alert

Telegram, webhook, or email when an agent errors or an automation stalls.

🪶Zero deps

A stdlib Python server and one HTML file. No Node, no Docker required — but a Docker image ships too.

Quickstart

# clone and run — no build step, no dependencies
git clone https://github.com/archonhq/archon.git
cd archon
python -m archon.cli serve --sessions-dir ~/.openclaw-autoclaw/agents/main/sessions

# then open
http://127.0.0.1:8000

The dashboard is served locally. Nothing leaves your machine — events never touch a third-party server.

One contract, many frameworks

framework logs ──► adapter ──► telemetry events ──► dashboard (HTTP/SSE)
                                        ▲
                                   control API
                                        │
framework APIs ◄─────── executor ◄──────┘

Adapters translate each framework into one JSON event stream (the contract). The dashboard and control API consume only that — so a new framework is one adapter away. OpenClaw ships today; Claude Code, CrewAI, n8n, and Make are on the roadmap.
